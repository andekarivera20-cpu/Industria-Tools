Privacidad

Última actualización: 28 de septiembre de 2026.

Calculadoras y datos introducidos

Los valores que introduces en las calculadoras se procesan localmente en tu navegador. IndusTools no dispone de un backend propio al que se envíen esos valores.

Favoritos e historial

Estas funciones utilizan almacenamiento local del navegador (localStorage) para conservar información en tu dispositivo.

Google Analytics

IndusTools utiliza Google Analytics 4 únicamente si aceptas la analítica mediante el aviso de privacidad. El identificador de medición utilizado por este sitio es G-YDD26E1PNQ.

La analítica se utiliza para obtener estadísticas agregadas sobre visitas y uso de la web, por ejemplo qué herramientas se utilizan más. IndusTools no envía a Analytics los números o valores técnicos que escribes dentro de las calculadoras.

Si rechazas la analítica, el script de Google Analytics no se carga y las calculadoras siguen funcionando. Puedes volver a abrir las preferencias desde el enlace “Preferencias de privacidad” del pie de página.

Alojamiento

El sitio está alojado mediante GitHub Pages. GitHub puede tratar datos técnicos necesarios para prestar el servicio, como direcciones IP y registros de acceso, conforme a sus propias políticas.

Cambios futuros

Si se incorporan publicidad, afiliación u otros servicios externos, esta política se actualizará antes de activarlos.
